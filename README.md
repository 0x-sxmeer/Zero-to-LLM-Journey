# Zero to LLM Journey

This repository is my personal build log and note-tracker for the [Zero to LLM Engineer Roadmap](https://github.com/path-to-roadmap-or-link).

## Goals
- Secure a professional AI/ML engineering role.
- Build the technical capability to start an AI/LLM startup.
- Deeply understand how to build LLMs from scratch.

## Project Structure
- `build_log.md`: A weekly log of what I built, learned, and struggled with.
- `PhaseX_.../`: Folders for each phase containing my notes (`notes.md`) and code exercises.
